## 5. 이 문서를 쓰는 이유

값이 비었을 때 물어야 할 것은 둘이다.

```
원본에 없나?          → 없으면 논문으로 보충. confirmed=N
우리가 안 읽었나?      → 읽으면 나올 수 있다. confirmed=Y 가 될 수 있다
```

지금까지 "없다" 고 판단했다가 뒤집힌 것이 여럿이다.

```
"기준온도 1차 출처가 없다"          → 농작업일정 첨부에 13종 있었다
"채소류 생육 및 장애온도 표가 없다"    → 검색어가 틀렸을 뿐 17개 호에 있었다
"수박은 고온해 표에 없다"            → 6~7월 호 5개에 있었다
"벼 단계별 규칙이 없다"             → 월간회보 제6호 표[102] 에 10단계가 있었다
"마늘·양파 동해 기준이 없다"          → 월동작물 동해한계온도표에 있었다
"한계온도표는 16개 호에 있다"         → 18개다. PDF 판 2개를 못 읽고 있었다
"장애온도는 짝을 맞출 수 없다"         → PDF 판은 행마다 짝이 맞는다
```

**일곱 다 "안 읽어서" 였다.** 그래서 안 읽은 목록을 따로 적어둔다.

특히 뒤의 셋은 **같은 자료의 PDF 판본을 안 읽어서** 생겼다. 판본이 다르면 다른 자료다.
