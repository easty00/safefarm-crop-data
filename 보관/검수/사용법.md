# 수집 결과 점검 — 사용법

## 이게 뭐야?

지금까지 모은 것에 **빠진 게 없는지 기계적으로 세는** 프로그램이야.

**새로 받는 건 없어.** 이미 있는 결과만 읽어. 1~3분이면 끝나.

```
cd "C:\Users\lecra\Desktop\safe\api테스트\검수"
python audit.py
```

## 왜 만들었나

지금까지 놓쳤다가 뒤늦게 찾은 실수가 아홉 건인데 **원인이 거의 같아.**

```
<h2>만 보고 잘라서 재배법이 통째로 빌 뻔했다
응답 13칸 중 3칸만 쓰고 나머지를 버렸다
파서를 한 호만 보고 만들어 2023년을 절반 넘게 놓쳤다
표 한 행에 이름-값 쌍이 두 개인 걸 못 봐서 절반을 잃었다
단위가 머리글에 있어 21행이 0행으로 나왔다
```

전부 **"한 표본만 보고 형식을 단정했다"** 야. 그래서 점검도 그 축으로 다섯 가지를 봐.

| | 무엇을 보나 |
|---|---|
| ① 응답 칸 | 응답에 있던 값이 CSV 어딘가에 살아 있나 |
| ② 건수 | 목록 수 = 받은 파일 = 판독 본문 인가 |
| ③ 구간 편차 | 연도·분류별로 추출량이 갑자기 떨어지는 데가 있나 |
| ④ 이상치 | 온도 100℃, 출수기 12.31 같이 말이 안 되는 값 |
| ⑤ 안 쓴 표 | 뜯어놓고 아무 규칙에도 안 쓴 표가 얼마나 되나 |

## ① 은 값으로 맞대야 해 — 여기서 한 번 틀렸어

처음엔 **태그 이름**과 CSV 칸 이름을 맞댔어. 그랬더니 40개가 "없음" 으로 나왔는데
**전부 거짓이었어.** 우리 스크립트가 칸 이름을 한글로 바꿔 담거든.

```
beginMon → 시작월        rtnFileCours → 파일경로
endEra   → 종료순        cntntsSj     → 제목
```

이름은 다르지만 값은 멀쩡히 들어 있어. 그래서 **값**으로 맞대도록 고쳤고 40 → 8건이 됐어.

판정은 세 가지야.

| 판정 | 뜻 |
|---|---|
| `O` | 표본 값의 절반 이상을 CSV 에서 찾음 |
| `일부만` | 일부만 찾음. **목록은 여러 해를 받았는데 CSV 는 고른 해만 담아서** 그럴 수 있어 |
| `-` | 값이 두 글자 이하라 확인 못 함 (우연히 다른 칸에서 걸려서 의미가 없어) |
| `**없음**` | 표본을 하나도 못 찾음. **여기만 보면 돼** |

## 결과물

```
결과/
  점검결과.md      ★ 이걸 나한테 보여주면 돼
  응답칸점검.csv    응답 칸별 판정 (일부만·- 포함 전부)
  건수점검.csv      서비스별 목록/파일/본문/0바이트/용량
  구간편차.csv      연도·분류별 추출량
  이상치.csv        말이 안 되는 값 + 원문
  안쓴표.csv       ★ 뜯어놓고 안 쓴 표의 머리글
```

### ⑤ 안쓴표.csv 가 제일 중요해

재해예방정보 한 문서에서만 표를 133개 뜯었는데, 규칙으로 옮긴 건 네 종류뿐이야.
나머지에 뭐가 들었는지 **아직 아무도 안 봤어.** 쓸모가 없어서가 아니라 안 봐서야.

`안쓴표.csv` 는 그 표들의 머리글을 많이 나온 순으로 보여줘. 여기서 쓸 만한 게 보이면
`재해규칙/rules.py` 에 알아보는 규칙을 하나 더 추가하면 돼.

## 판정이 걸렸을 때 뭘 해야 하나

| 걸린 곳 | 확인할 것 |
|---|---|
| ① `**없음**` | 그 칸이 정말 필요한 값인지. 필요하면 수집 스크립트에 칸을 추가 |
| ② 목록 > 파일 | 각 서비스 `요약.md` 의 실패 목록과 맞춰봐. 농사로에 첨부가 없는 건이 대부분 |
| ③ `**적음**` | 그 연도·분류만 형식이 다를 수 있어. 본문을 직접 열어봐야 해 |
| ④ 이상치 | `원문` 칸을 보고 읽는 규칙을 고쳐 |
| ⑤ 안 쓴 표 | 머리글을 훑어 쓸 만한 게 있으면 recognizer 추가 |

## 알아둘 것 — 이 점검이 못 잡는 것

정직하게 말해둘게. 이건 **기계적으로 셀 수 있는 것만** 봐.

```
못 잡는 것   문장 속에 있는데 표로 안 만든 값
            표는 읽었는데 뜻을 잘못 해석한 값 (적온을 기준온도로 쓴 것 같은)
            애초에 API 에 없어서 다른 데서 구해야 하는 값
```

그건 사람이(또는 내가) 본문을 읽어야 나와. 이 점검은 **읽을 곳을 좁혀주는 도구**지
읽기를 대신하는 게 아니야.

## 언제 돌리나

수집이나 추출 스크립트를 고친 다음에는 한 번씩 돌려. 특히 파서를 고쳤을 때.
결과 파일은 매번 새로 써.
