# 재해 판정 규칙 정리 — 사용법

## 이게 뭐야?

지금까지 받아둔 자료 셋에서 **재해 판정에 쓸 숫자만 뽑아 한 표로 모으는** 프로그램이야.
로드맵 6단계야.

**새로 받는 건 하나도 없어.** 인터넷을 안 쓰고 `.env` 도 필요 없어. 2~5분이면 끝나.

```
재해규칙/
  rules.py       ← 실행할 것
  사용법.md       ← 지금 읽는 것
  결과/          ← 새로 생김
```

| `농작업일정/결과/첨부_표.csv` | 작물별 기상재해·생리장해 대책 |

셋 다 이미 돌려놨으니 그대로 읽기만 해.

## 가장 값진 표

저온해 보고에 이 표가 **42개 문서**에 들어 있어.

```
작물종류 ¦ 품종             ¦ 위험발령 생육단계 ¦ 위험발령 기준(최저기온)         ¦ 재해종류
사과    ¦ 조생종 중생종 (만생종) ¦ 휴면기(1월)     ¦ ≤-25℃ (주의) ≤-30℃ (위험)   ¦ 동해
사과    ¦ 조생종 중생종 (만생종) ¦ 발아기         ¦ ≤-2.8℃ (주의) ≤-5.0℃ (위험) ¦ 저온해
사과    ¦ 조생종 중생종 (만생종) ¦ 개화기         ¦ ≤-1.1℃ (주의) ≤-2.2℃ (위험) ¦ 저온해
```

**작물 · 숙기 · 생육단계 · 등급별 기준값이 이미 다 갈려 있어.** 우리가 만들려던 게 이미 있는 거야.
`품종` 칸에 조생종·중생종·만생종이 들어 있어서 숙기 논의에도 바로 쓸 수 있어.

고온해 쪽도 같은 모양이야.

```
사과  ¦ 과실비대기-수확기(조/중) ¦ 최고기온 30℃ 이상(주의), 최고기온 32℃ 이상(위험)
배   ¦ 과실비대기            ¦ 최고기온 33℃ 이상 2일이상 지속(주의), 35℃ 이상 2일이상(위험)
가루쌀 ¦ 묘대기               ¦ 평균기온 24℃ 이상(주의), 평균기온 26℃ 이상(위험)
```

**지속 일수 조건까지 있어.** "33℃ 이상이 2일 이상" 은 하루만 넘어도 경보를 띄우면 안 된다는 뜻이야.

## 네 가지 표 모양을 알아본다

문서마다 표 모양이 달라서 네 가지로 나눠 읽어.

| 알아보는 표 | 어떻게 찾나 |
|---|---|
| 작물별 위험발령 기준 | 머리글이 `작물종류` 로 시작 |
| 과수 동해 한계온도 | 머리글에 `동해 한계온도` |
| 작물별 최저 한계온도 | 머리글이 `작물별` + `동해온도`/`냉해온도` |
| **채소류 생육 및 장애온도** | 머리글이 `작물별` + `장애온도` |
| 벼 생육시기별 한계온도 | 머리 두 줄에 `최적`·`최저`·`최고` |
| 동해·우박·일소 피해율 | 머리글에 `피해율` + 기준 열(최저기온·우박크기·토양습도) |
| 월별 생육단계 | 머리글에 `월별` + `생육단계` |

### 「채소류의 생육 및 장애온도」 — 한 표에 다섯 가지

2023~2026년 **17개 호에 그대로 재수록**되는 표입니다. 이것 하나에서 15작물이 나옵니다.

```
작 물 별 ¦ 최고한량계 ¦ 적온(낮) ¦ 적온(밤) ¦ 최저량계 ¦ 동해온도 ¦ 장애온도
토마토    ¦ 35       ¦ 25~20   ¦ 13~8    ¦ 5      ¦ -1~-2  ¦ 30℃이상 : 공동과발생
가지      ¦ 35       ¦ 28~23   ¦ 18~13   ¦ 10     ¦ 0~2    ¦ 35℃이상 : 낙화·낙과
고추(피망) ¦ 35       ¦ 30~25   ¦ 20~15   ¦ 12     ¦ 0~2    ¦ 25℃이상 : 화분기능상실
```

`장애온도` 칸은 조건과 증상이 콜론으로 갈려 있어 따로 풀어 담습니다.
증상은 `비고` 칸에 남깁니다(`공동과발생`·`낙화`·`화분기능상실`).

⚠ **`적온` 은 담지 않습니다.** 재해 판정 기준이 아닙니다.
⚠ **`최저` 는 재배 한계이지 `base_temp` 가 아닙니다.** 상추 국내 8 ↔ 논문 3.5~4.5.

### ⚠ 칸 안에 줄이 여러 개인 표가 있어

과채류·엽채류 한계온도 표가 이 모양이야.

```
작 물 별 ¦ 모기를 때 ¦ 꽃눈생기기전 ¦ 동해온도
딸기      ¦ 10      ¦ 3~5        ¦ 0
토마토     ¦ 10      ¦ 5          ¦ -1~-2      ← 이 여섯 줄이 '한 칸' 안에 들어 있어
```

보기엔 7행짜리 표인데 실제로는 **2행짜리 표에 칸마다 6줄씩** 들어있어. 칸 안의 줄을
공백으로 이어붙이면 `딸기 토마토 오이` 와 `10 10 12` 가 되어서 **짝을 영영 잃어버려.**

그래서 이 프로그램은 **칸 안의 줄바꿈을 살려서** 읽고, 세로로 다시 짝지어.
(`농작업일정/attach.py` 는 줄을 이어붙이는데, 그쪽 표는 이 모양이 아니라서 괜찮아.)

## 결과물

```
결과/
  요약.md                ★ 이걸 나한테 보여주면 돼
  disaster_rules.csv     ★ 판정 규칙 (중복 뺀 것)
  disaster_rules_전체.csv  중복 포함. 어느 호에 몇 번 실렸는지 볼 때
  참고수치표.csv           감수율·피해율·부패율 표 (규칙은 아니지만 값이 있는 것)
  병해충경보.csv            경보/주의보/예보 1,339행
  작물별대책.csv            농작업일정의 기상재해 대책문
```

### disaster_rules.csv

```
출처파일, 계열, 연도, 표번호, 표종류,
작물, 품종숙기, 생육단계, 재해종류,
지표, 부등호, 값, 단위, 지속일, 등급,
조건원문, confirmed, 중복수
```

한 줄이 판정 하나야. 이렇게 읽으면 돼.

```
사과 · 발아기 · 저온해 · 최저기온 <= -2.8℃ · 주의
배  · 과실비대기 · 고온해 · 최고기온 >= 33℃ · 2일이상 · 주의
```

- `지표` 는 `최저기온` / `최고기온` / `평균기온` 이야. **일평균이 아닌 걸 주의해서 봐.**
  기상 데이터를 붙일 때 일최저·일최고를 따로 가져와야 해
- `지속일` 이 비어 있으면 하루만 넘어도 해당이야
- `등급` 은 관심 / 주의 / 경계 / 경고 / 위험 / 심각
- **`조건원문` 을 꼭 같이 봐.** 자동으로 읽은 값이 맞는지 확인하는 유일한 방법이야
- `confirmed=Y` 는 표에서 그대로 옮긴 것, `N` 은 문장에서 캐낸 것

### 중복 처리

같은 표가 여러 호에 재수록돼서 같은 규칙이 여러 번 나와. 그래서 두 파일로 나눴어.

```
disaster_rules.csv       같은 (작물·단계·재해·지표·부등호·값·등급) 은 첫 번째만
disaster_rules_전체.csv    전부. 몇 번 실렸는지는 중복수 칸에
```

**버린 게 아니라 나눠둔 거야.** 어느 해에 값이 바뀌었는지 보려면 전체 쪽을 봐.

### 참고수치표.csv

감수율·피해율·부패율 표는 "몇 ℃면 경보" 꼴이 아니라서 규칙으로 못 바꿔.
그래도 값이 아까우니 긴 꼴(파일·표번호·행·열·값)로 통째로 담아뒀어.

```
콩 침수피해기간별 피해율 · 감자 수확기 침수시간별 부패율
벼 생육단계별 침관수 기간에 따른 수량 감소율 · 채소류 침수기간별 피해율
```

나중에 "침수 3일이면 수량 몇 % 감소" 같은 판정을 만들 때 쓸 재료야.

## 다 돌린 다음에 할 일

`결과/요약.md` 를 보여줘. 내가 볼 건 이 다섯 가지야.

1. **판정 규칙이 몇 행인가** — `confirmed=Y` 비율이 핵심이야
2. **표 종류별 작물 수** — 어느 표가 작물을 넓게 덮는지
3. **작물별 규칙 수 상위 30** — 우리 대상 작물이 들어있는지
4. **등급이 붙은 규칙 수** — 등급이 없으면 경보 단계를 못 나눠
5. **판독 실패** — 0이어야 해

그 다음에 `조건원문` 을 눈으로 훑어서 잘못 읽은 값을 골라낼 거야.

## ⚠ 이 값들을 base_temp 로 쓰면 안 돼

로드맵 §1 에 적은 세 구분이 그대로야.

```
한계온도  피해가 난다         → 여기(disaster_rules.csv)
기준온도  생육이 안 진행된다   → crops.base_temp. 아직 못 구했어
적온     가장 잘 자란다      → 어느 쪽도 아님
```

**이 폴더 결과는 전부 첫 번째야.** 적산온도 계산에 끌어다 쓰면 안 돼.

## 문제가 생기면

- `... 결과가 없습니다` → 그 폴더의 스크립트를 먼저 돌려야 해
- `모르는 형식` → 앞 4바이트로 판정하는데도 모르는 게 나온 거야. 파일명 알려줘
- 규칙이 이상한 값(예: 사과 300℃) → `조건원문` 칸을 보여줘. 읽는 규칙을 고칠게
- 규칙이 거의 안 나오면 → 표 모양이 바뀐 거야. 요약.md 의 표 종류별을 보여줘
