OPEN API 이용 안내
1. 개요
농촌진흥청 농사로 OpenAPI는 다양한 농업기술정보를 유용하게 활용할 수 있도록 공개한 개발자 인터페이스입니다.
2. 이용안내
농촌진흥청 농사로 OpenAPI를 이용하기 위해서는 로그인 한 후 별도의 신청이 필요합니다. 농사로의 [汫╨Open API 이용안내汫h] 페이지에서 Open API 서비스 신청 및 매뉴얼 및 샘플 파일을 다운로드 받을 수 있습니다. 
3. 제공 API서비스
3.1 Open API 제공 방식
농사로 Open API는 동적 JavaScript 로딩을 이용한 AJAX 방식을 제공합니다.
3.2 텍스트 인코딩
농사로 Open API는 모든 텍스트 데이터를 U湯湷TF-8로 제공합니다.

제공되는 샘플소스를 편집기로 열어보면 위와 같은 형태의 코딩이 되어 있습니다.
제공되는 샘플소스를 서비스할 소스에 삽입하고 아래와 같이 변경하면 됩니다.
변경할 부분 1은 농사로에서 발급받은 인증키를 소스에 기입하면 됩니다.
변경할 부분 2는 샘플소스와 같이 제공되는 각 언어별 콜백페이지를 서버에 업로드 후
해당 url을 기술하면 됩니다.
 
각 서비스 별로 샘플소스가 약간의 차이가 있으니 다른 서비스의 샘플소스를 사용하지 마십시오.
8. 기타사항
8.1 ajax 방식 사용 시 한글 깨짐 현상이 발생하는 경우
제공되는 콜백페이지의 문자셋 설정을 변경하여 적용하십시오.
8.2 농사로 open API 서버와 통신이 원활하지 않은 경우
서버 방화벽에서 농사로 오픈API 서버와 80 포트 통신이 막혀있는지 확인하십시오.
