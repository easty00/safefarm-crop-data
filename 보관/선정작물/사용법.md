## 선정 결과 — 14작물 / 22작형

작물 하나가 작형을 여럿 가지므로 행이 늘어납니다. 배추는 봄·가을·고랭지 셋입니다.

| 계절(수확) | 작형 |
|---|---|
| 봄 | 배추_봄 · 무_봄 · 상추_봄 · 당근_봄 · 시금치_월동(1~3월) |
| 여름 | 수박 · 감자_봄 · 배추_고랭지 · 무_고랭지 · 마늘 · 양파 · 가지 · 방울토마토 |
| 가을 | 벼 · 배추_가을 · 무_가을 · 고추 · 파 · 당근_가을 · 감자_가을 · 상추_가을 · 방울토마토_고랭지 |
| 겨울 | 시금치_월동 · (재배 중: 마늘 · 양파 · 파) |

겨울은 **수확** 기준으로 시금치 하나뿐입니다. **밭에 서 있는** 기준으로 보면
마늘·양파·파·시금치 넷이라 화면에 보여줄 것은 있습니다.

## ⚠ 값을 볼 때 조심할 것

### 상추 1,400~1,700 은 목표값이 아닙니다

원문이 "꽃대신장은 적산온도 1,400~1,700℃에서 나타남" 입니다. **언제 수확하냐가 아니라
언제 써지냐**입니다. `target_sum` 이 아니라 `disaster_rules` 의 추대 경보로 가야 합니다.
표에는 남겨두었지만 그대로 목표값으로 쓰면 안 됩니다.

### 마늘 4℃ 는 잎마늘 값입니다

`마늘(잎마늘)` 문서에서 나온 값이라 일반 마늘에 그대로 쓸 수 있는지 확인이 필요합니다.
그리고 마늘은 애초에 적산온도로 안 풀립니다 — 쪽 분화에 5℃ 이하 30일 이상이
필요한 저온 요구도 작물입니다(로드맵 §6-4). **마늘만 적산 진행률 대신
달력 + 재해 경보로** 다루는 편이 맞습니다.

### 가지 기준온도는 값이 둘입니다

```
Safe-farm 더미      base_temp 12.0
농작업일정 본문       "17℃ 이하에서는 생육이 정지됨"
```

5℃ 차이입니다. 17℃로 잡으면 봄철 상당수 날이 0이 되어 적산이 거의 안 쌓입니다.
국제 문헌은 보통 10~15℃ 쪽입니다. 셋 중 무엇을 쓸지 정하고 `confirmed` 를 붙여야 합니다.

## 스크립트가 사람 손을 빌리는 곳

자동으로 못 푸는 게 둘 있어서 `SPEC` 에 손으로 적어두었습니다.

### 하나. 작형 짝짓기

배추·무·상추·감자·당근은 한 문서에 봄·가을 작형이 **라벨 없이 섞여** 있습니다.
기계가 첫 파종과 마지막 수확을 집으면 이렇게 됩니다.

```
배추  씨뿌림 1월 중순  →  수확 12월 상순  =  324일   ❌ 실제로 이렇게 나왔었다
```

봄에 뿌린 것과 가을에 거둔 것을 짝지은 값입니다. 그래서 `SPEC` 에 작형마다
**시작월과 수확월을 못 박았습니다.** 추측이 아니라 명시라 나중에 되짚을 수 있습니다.

작형 라벨(`정보구분` 칸)이 붙어 있는 것은 11종뿐입니다. 수박 `노지재배`,
가지 `봄재배(조숙,노지)`, 방울토마토 `조숙재배`·`고랭지재배` 가 그 덕에 자동으로 갈립니다.

### 둘. 작업명이 작물마다 다름

```
벼   "모내기때"    ← '이앙' 도 '심기' 도 안 들어 있다
무   "씨뿌림"      ← '씨뿌리' 로 찾으면 안 걸린다
감자  "밭준비 및 파종"
```

정규식 하나로 안 되어 작물별로 시작 작업 패턴을 `SPEC` 에 적었습니다.

### 셋. 재배일수는 구간의 중앙끼리 잇는다

파종 시작 ~ 수확 종료로 재면 작형 범위의 양 끝이라 최장값이 나옵니다.

```
봄배추  파종 시작 ~ 수확 종료   142일   ❌ 실제 봄배추는 80~90일
        파종 중앙 ~ 수확 중앙    86일   ✅
```

앞의 142일은 "1월 중순에 뿌린 포기가 6월 초에 수확될 때까지"이지
"한 포기가 자라는 데 걸리는 날"이 아닙니다.

## 시설을 어떻게 걸렀나

노지 작형이 있는 것만 넣었습니다. 근거는 둘입니다.

```
① 작물 이름           고추(촉성재배) · 고추(꽈리고추 반촉성) · 딸기(촉성재배)  → 제외
② 정보구분 칸의 작형    "생육과정(주요농작업) - 노지재배"                    → 채택
```

②로 갈리지 않는 작물은 파종·수확 시기로 사람이 판단했습니다. 대표적으로 **오이**는
작형이 하나뿐인데 10~11월 씨뿌림 → 12월 정식 → 2~5월 수확이라 시설 전용입니다.
통계청 노지채소 조사 품목에는 들어 있지만 농사로 데이터에 노지 작형이 없어 뺐습니다.
참외·딸기도 같은 이유로 빠졌습니다.
