# 14작물로 거르기 — 사용법

## 이게 뭐야?

뽑아둔 결과 표 전부를 **선정 14작물 행만** 따로 모으는 프로그램이야.
로드맵 A-2야.

**새로 받는 건 없어.** `*/결과/*.csv` 를 읽기만 해. 10초면 끝나.

```
cd "C:\Users\lecra\Desktop\safe\api테스트\선정작물"
python filter14.py
```

## 왜 필요한가

결과 표가 96,807행인데 **14작물 밖이 대부분**이야. 화훼 839품종, 축산, 버섯,
과수 전체가 섞여 있어. 전부 읽을 수는 없고 읽을 범위를 먼저 좁혀야 해.

```
전체 96,807행  →  14작물 11,553행   (12%)
```

## 이름 맞추기가 이 일의 전부야

작물 이름이 표마다 다르게 적혀 있어.

```
농작업일정   벼 기계이앙재배 · 고추(보통재배) · 무(고랭지재배) · 토마토,방울토마토
품종정보     논벼 · 방울토마토 · 결구상추(양상추)
병해충       벼등 · 여름배추 · 고랭지씨감자 · 마늘,양파 · 토마토,고추,파프리카,상추등
```

그래서 작물마다 **넣을 이름(alias)과 뺄 이름(exclude)** 을 적어뒀어.
실제로 표에 나온 이름 34종을 세어보고 적은 거야. 추측이 아니야.

### ⚠ 한 글자 이름은 부분일치로 못 걸러

`무`·`파`·`벼` 가 문제야. 처음엔 부분일치로 만들었는데 이런 게 걸렸어.

```
무 ← 꽃사과나무 · 천마균류(뽕나무버섯류) · 키다리병,깨씨무늬병등 · 포도(무가온)
파 ← 아스파라거스 · 벼 직파재배
벼 ← 벼줄무늬잎마름병
```

**뺄 목록으로는 못 막아.** 새 이름이 나올 때마다 또 걸리거든.
그래서 한 글자는 **앞뒤에 한글이 붙지 않은 것**만 받도록 고쳤어.

```
무(고랭지재배)  → 뒤가 괄호라 통과 ✅
꽃사과나무      → 앞이 '나' 라 걸러짐 ✅
```

`배추` 같은 두 글자는 `여름배추` 를 받아야 하니까 부분일치를 쓰되,
`양배추`·`브로콜리(녹색꽃양배추)` 를 뺄 목록에 넣었어.

## 결과물

```
선정작물/결과/
  14작물_요약.md      ★ 이걸 나한테 보여주면 돼
  14작물/             표별로 거른 CSV (원본 칸 + `_선정작물` 칸)
  매칭표.csv          어떤 원본 이름이 어느 작물로 갔는지 전부
  요약.csv            표별 전체 행 → 남은 행
  작물칸없음.csv       작물 칸이 없어 못 거른 표
```

거른 CSV 에는 **원본 칸을 그대로 두고 `_선정작물` 칸만 더했어.**
한 행이 두 작물에 걸리면 `마늘 | 양파` 처럼 들어가.

### 매칭표.csv 를 꼭 봐

**이게 이 스크립트에서 제일 중요한 파일이야.** 이름이 잘못 붙으면 그 뒤 작업이 전부
틀어지는데, 오류가 조용히 지나가거든. 요약.md 맨 아래에도 작물별 원본 이름 목록이 있어.

## 작물 칸이 없어 못 거른 표

```
농작업일정/농작업시기.csv 의 일부 · 재해예방정보/목록.csv · 주간농사정보/목차.csv
재해규칙/참고수치표.csv · 농업지대.csv · 병해충발생정보/항목.csv
```

작물별로 나뉘지 않는 표야. 문서 단위이거나 지역 단위라 통째로 봐야 해.
이건 거르기의 한계지 빠뜨린 게 아니야.

## 이름이 바뀌거나 작물이 늘면

`filter14.py` 맨 위 `CROPS` 표만 고치면 돼. 작물 하나가 한 줄이야.

```python
"배추": (("배추",), ("양배추", "꽃양배추", "브로콜리", "컬리플라워")),
         ^^ 넣을 것    ^^ 뺄 것
```

고친 뒤 **반드시 `매칭표.csv` 를 다시 봐.** 뺄 목록이 하나 빠지면 조용히 오염돼.
