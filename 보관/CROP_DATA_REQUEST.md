# A. 프로젝트 배경

## A-1. 무엇을 만드는가

**위성과 기상 데이터로 소규모 영농인의 의사결정을 돕는 서비스.**

텃밭을 지도에 찍고 작물을 고르면, 생육 단계에 맞는 할 일과 재해 경보를 알려준다.

```
논 탭    벼        파종일 기준 적산온도 진행률
밭 탭    채소      파종일 기준 적산온도 진행률
과수 탭  단감·포도  연간 달력 + 적지 판정 (수령이 있어 진행률 개념 없음)
```

## A-2. 핵심 구조 — 판단은 코드, 문장은 LLM

```
[1단계] 코드가 계산
  기온 누적 → 적산온도 → 생육단계 판정
  강수 합계 → 관수 필요 여부
  농진청 기준과 대조 → 재해 경보 발동

[2단계] 계산 결과만 Claude에 전달
  작물명 · 파종 후 일수 · 누적/목표 · 다음 단계까지 일수
  · 7일 강수 · 발동 재해 · 대책

[3단계] 정해진 JSON 형식으로 받아 화면 표시
  { "요약": …, "할일": […], "주의": […] }
```

**판단까지 LLM에 맡기면 근거 없는 수치를 지어냅니다.**
이 구조라야 "이 조언의 근거는 이 계산식"이라고 말할 수 있습니다.

**→ 그래서 작물 데이터는 "계산 가능한 숫자"여야 합니다.** 설명문이 아니라.

## A-3. 대상 작물 (8종)

| 탭 | 작물 | 품종 |
|---|---|---|
| 논 | 벼(기계이앙) | 조생 · 중생 · 중만생 |
| 밭 | 배추 | 단일 (노지 가을재배 우선) |
| 밭 | 고추 | 단일 (보통재배. 시설 제외) |
| 밭 | 마늘 | 단일 (노지) |
| 과수 | 단감 | 단일 (부유 기준) |
| 과수 | 포도 | 단일 (무가온. 캠벨얼리/거봉) |

**시설재배(촉성·반촉성·표준가온)는 1차 제외.** 노지 기상 판정 구조와 맞지 않음.

```
검색어: 기준온도 · 발육영점온도 · 영점온도 · GDD · 유효적산
결과:   0건
```

**있는 것**
```
생육 적온      배추 발아 20~25℃ · 생육 15~20℃ · 결구 15~16℃
작형별 일정    가을배추 씨뿌림 8월 상~하순 · 수확 10월 중~12월 상순
재해 대책      가을가뭄 → 스프링클러 물주기, 짚 덮기
언피해 온도    배추 -3~-4℃ · 마늘 -5℃
```

**없는 것**
```
기준온도(base temperature)
목표 적산온도(target)
생육단계별 적산온도 구간
```

**유일한 예외 — 벼(기계이앙)**
```
벼베기 적기 = 출수 후 적산온도 1,100~1,200℃
지역·품종별 일수  중부 50/53/57일 · 호남 52/55/60일 · 영남 50/54/58일
```

> **적온은 기준온도가 아닙니다.**
> 생육적온 15~20℃ = "이 온도가 좋다" → 재해 판정용
> 기준온도 5℃ = "이 위로 세기 시작한다" → 계산용

## B-3. 적산온도 계산 방식 — 세 가지가 있음

조사 결과 한국 농업에서 쓰는 방식이 셋으로 갈립니다.

```
① 단순적산온도    Σ (일평균기온)                    모든 날 더함
② 적산온도(관행)  Σ (일평균기온), 기준온도 이상인 날만  ← 빼지 않고 거르기만
③ 유효적산온도    Σ (일평균기온 − 기준온도)          ← 빼기. 이것이 GDD
```

**기상청 기후통계 정의 (②)**
> 생육 일수의 일평균기온을 적산한 것. 일평균기온은 해당 작물이 활동할 수 있는
> 최저 온도(기준 온도) 이상의 것만을 택한다.
> 기준 온도: 가을 채소 5℃, 온대 지방 여름철 작물 10℃

**유효적산온도 정의 (③)**
> 1일 평균기온에서 발육영점온도를 빼고 누적.
> 발육영점온도는 여러 온도에서 발육속도 V를 측정해 `V = A + BT` 회귀선을 구하고,
> V=0이 되는 온도로 실험 결정. K = 1/B.

**→ 발육영점온도는 실험값입니다. 임의로 정할 수 없습니다.**

**농진청 벼 1,100~1,200℃ 검산**
```
출수 후 50일 × 등숙기 평균 22℃ = 1,100   ✅ ①② 방식과 일치
base 7 빼면  50 × (22−7) = 750           ❌ ③ 아님
```
등숙 적정기온 20~22℃(출수 후 40일 평균), 품종별 등숙적산온도
오대벼 1,194 · 수라벼 1,097 · 일미벼 1,138 · 일품벼 1,087 — 모두 부합.

## B-4. 방식 선택 — ③ GDD 방향

| | ③ GDD | ② 적산온도 |
|---|---|---|
| 국제 표준 | ✅ | 국내 관행 |
| 저온 구간 정확도 | ✅ | 낮음 |
| 봄·가을 작물 | ✅ 유리 | 불리 |
| 기준온도 | 실험값 필요 | 분류 참고값 |
| 농진청 벼 값 호환 | 재계산 | 그대로 |

**GDD가 정확합니다.** 6℃인 날과 20℃인 날의 차이를 ②는 거의 못 잡습니다.

```
3월 일평균 6℃ 인 날
  ② (기준 5℃)  6 을 더함
  ③ (기준 5℃)  1 을 더함    ← 생육 속도 차이를 반영
```

**⚠ 두 방식을 섞지 마세요.** `crops` 테이블에 `sum_method` 컬럼을 두고 작물마다 명시할 것.

# D. 얻은 데이터를 어떻게 쓸 것인가

## D-1. 목표 적산온도 역산 — 핵심 로직

**농작업일정 날짜 + 기상청 실측 기온 → 목표 적산온도**

```
① 작물별 대표 지역 선정 (주산지 관측소)
② 농작업일정에서 파종·수확 시기 추출
③ 순(旬)을 날짜로 변환    상순=5일 · 중순=15일 · 하순=25일
④ 기상청 arcltr_sfc_day 로 그 기간 일평균기온 확보
⑤ 선택한 방식(①②③)으로 누적
⑥ 최근 10년 반복 → 평균 = 목표 적산온도
```

**예시 — 가을배추**
```
농작업일정  씨뿌림 8월 상순~하순 · 수확 10월 중순~12월 상순
중앙일      씨뿌림 8/15 · 수확 11/5   (82일)
계산        8/15~11/5 일평균기온을 base 5℃ 로 GDD 누적
반복        2016~2025 → 평균
```

## D-2. ⭐ 벼로 방법을 먼저 검증할 것

**농진청이 정답을 이미 줬습니다.**

```
농진청   출수 후 적산온도 1,100~1,200℃ · 호남 중생종 55일

검증     출수 중앙일부터 55일간을 ①②③ 세 방식으로 각각 누적
         최근 10년 평균

판정     ①② 결과가 1,100~1,200 범위에 들어오는가
         → 들어오면 파이프라인 정상. 다른 작물에 적용 가능
         → 동시에 ③(GDD) 값도 확보됨
```

**이걸 먼저 하세요.** 방법이 틀린 채 8종을 돌리면 전부 다시 해야 합니다.

## D-3. 기준온도 추정 — 자료가 없을 때

농작업일정에 **지역별 날짜**가 있다면 이 방법이 가능합니다.

**원리**: 기준온도가 맞으면 지역이 달라도 목표값이 비슷해야 한다.

```
중부  파종 4.15 ~ 수확 X    기온 낮음, 기간 김
호남  파종 4.25 ~ 수확 Y    기온 높음, 기간 짧음

base 를 0~15 로 바꿔가며 지역별 목표값 계산
→ 지역 간 편차가 최소가 되는 base 채택
```

```
base  0   중부 1850 · 호남 2100 · 영남 2050   편차 250
base  5   중부 1400 · 호남 1450 · 영남 1420   편차  50   ← 채택
base 10   중부  950 · 호남  800 · 영남  790   편차 160
```

**미검증 방법입니다.** 벼로 먼저 시험하세요. 벼는 지역별 일수가 명시돼 있어 검증 가능합니다.

## D-4. 생육단계 구간

같은 방식으로 단계별 시기를 날짜로 바꿔 각각 누적합니다.

```
배추 가을재배
  씨뿌림 8/15 → 아주심기 9/5     → 구간 1 (모 기르기)
  아주심기 9/5 → 결구 시작 10/5  → 구간 2 (잎·줄기 신장)
  결구 10/5 → 수확 11/5          → 구간 3 (결구)
```

**"파종 후 N일" 형태가 API에 있으면 훨씬 정확해집니다.** C-1 ② 확인 항목 참조.

## D-5. 재해 판정

```python
RULES = [
  {"crop":"배추", "name":"가을가뭄", "when": lambda w: w.rain7 < 5,
   "todo":["스프링클러 물주기","짚 덮기"], "source":"농진청 배추 농작업일정"},
  {"crop":"배추", "name":"결구기 고온", "when": lambda w,s: w.tmax > 25 and s=="결구",
   "source":"결구적온 15~16℃"},
  {"crop":"배추", "name":"언피해", "when": lambda w: w.tmin <= -3,
   "source":"농진청 언피해 -3~-4℃"},
]
```

**임계값은 우리가 정하지 않습니다.** 농진청 문서의 숫자를 그대로 옮깁니다.
`source` 컬럼을 반드시 채워 근거를 추적할 수 있게 하세요.

## D-6. 과수 적지 판정

과수는 진행률이 아니라 **그 땅이 그 작물을 키울 수 있는지**를 봅니다.

```
단감 (문서에 있음)
  연평균기온     13℃ 이상
  휴면기 평균    -1℃ 이상 (12~2월)
  휴면기 최저    -4℃ 이상
  성숙기 평균    10월 15℃ · 11월 9℃ 이상
  일조시간       2,340시간 이상

포도  ❌ 문서에 없음 → API에서 반드시 찾을 것
```

좌표 → 평년값 → 조건 대조 → 적지 여부 판정.

## E-2. ⚠ `source` 와 `confirmed` 를 반드시 채울 것

```

# G. 주의사항 · 함정

```
1. 적온 ≠ 기준온도       생육적온은 재해 판정용. 계산에 쓰면 안 됨
2. 방식 혼용 금지        ①②③ 중 하나로 통일. crops.sum_method 에 명시
3. 결측 -999            기상청은 null 이 아니라 -999
4. 순(旬) 변환          상순=5일 · 중순=15일 · 하순=25일 로 통일
5. 지역 구분            중부/호남/영남이 다름. 무시하면 값이 어긋남
6. 시설재배 제외         촉성·반촉성·표준가온은 1차 범위 밖
7. 마늘 특수            "쪽 분화에 5℃ 이하 30일 이상" — 저온 요구도.
                       적산만으로 판정 불가. 별도 로직 필요
8. 포도 적지 미확보      단감만 조건이 있음. 포도는 API에서 찾아야 함
9. confirmed 컬럼       역산·추정값은 반드시 N 으로 표기
```

```

                     → 시군 평균이 아닌 좌표 조회가 필요한 이유

                     → 위성은 주력이 될 수 없음

                     → 날짜·생육단계 없이는 위성 지수를 읽을 수 없음
                     → 적산온도가 주력인 근거
