# 재해예방정보 수집 — 사용법

## 이 폴더는 뭐야?

농사로 **농작물재해예방정보(`frcDsstrPrevnt`)** 하나만 맡는 폴더야.

```
재해예방정보/
  disaster.py     ← 실행할 프로그램 (이거 하나면 돼)
  사용법.md        ← 지금 읽고 있는 것
  결과/
    raw/          농사로가 보내준 원문 (2011~2026 목록 17개가 이미 들어있음)
    파일/          내려받은 문서 (계열/연도 로 폴더가 갈려. 2026 월간회보 3건이 이미 있음)
    본문/          문서를 글자로 바꾼 txt  ← 내가 읽을 건 여기야
```

`.env` 는 이 폴더에 안 넣었어. 프로그램이 **위쪽 폴더로 올라가면서 찾아** 써.

## 왜 23·24·25년이야?

전에 받아둔 목록을 연도별로 세어봤더니 이렇게 나왔어.

```
연도    월간회보  저온해  고온해  홍수해   합계
2021      12       6      5      2       25
2022      12      22      7      2       43
2023      12      20     10      3       45   ← 가장 풍부
2024      12      20     12      0       44   ← 가장 풍부
2025      11       3      0      0       14   ← 제10호 없음
2026       9       0      0      0        9   ← 아직 진행 중
```


**23·24년이 자료가 제일 많고, 25년은 최신이야.** 그래서 기본값이 이 세 해야.
2025·2026년에 저온해 보고가 줄어든 게 발행 중단인지 단순 미등록인지는 받아봐야 알아.

## 이 서비스에 뭐가 들어있나 — 네 계열

**월간회보만 있는 줄 알기 쉬운데 아니야.** 제목으로 갈라보면 네 종류가 섞여있어.

| 계열 | 어떤 문서 | 왜 중요한가 |
|---|---|---|
| **월간회보** | `제N호` — 연 12건 | 종합 안내서. 표가 제일 많아 |
| **저온해** | 동해 예측 보고. 1~5월·12월에 주마다 | **겨울 자료가 여기 있어.** 23·24년 연 20건 |
| **고온해** | 폭염 예측 보고. 수시 | 상한온도 근거 |
| **홍수해** | 수시 | 침관수 감수율 |

전에 "한파·동해 자료 미확보"라고 보고했던 건 **2026년만 봤기 때문**이었어.
연도를 넓히니까 저온해 계열이 통째로 나왔어. 그 정정이 이 폴더를 만든 이유야.

저온해 문서는 `.hwpx` / `.hwp` 라서 **PDF 인 월간회보보다 글자 추출이 훨씬 깨끗해.**

## 방침 — 거르지 않는다

본문에 **정규식 필터를 안 걸어.** 전문을 통째로 txt 로 저장해.

전에 "숫자 + 단위 + 비교말" 만 뽑는 필터를 썼다가, 제일 값진 세 개를 다 놓쳤거든.

```
벼 생육시기별 한계온도표   → 표라서 문장 패턴에 안 걸림
가루쌀 적산온도 700℃부터   → '부터' 가 비교말 목록에 없었음
침관수 감수율표           → 역시 표
```

그래서 **판단은 내가 전문을 읽고 해.** 프로그램은 다 가져다 놓기만 해.
응답으로 오는 칸도 하나도 안 버리고 `목록.csv` 에 다 넣어.

## 실행 방법

```

```

**기본이 2023·2024·2025년 전체, 103건.** 15~25분, 200~400MB 정도 될 거야.

### 먼저 가볍게 확인하고 싶으면

```
python disaster.py --no-files
```

목록만 받고 파일은 안 받아. 1분 안에 끝나고 `목록.csv` 만 나와.
계열 분류가 제대로 됐는지 보는 용도야.

### 옵션

| 옵션 | 뜻 |
|---|---|
| `--year 2023,2024,2025` | **기본값.** 쉼표로 여러 해 |
| `--year 2023,2024,2025,2026` | 2026년까지 넣어서 4년 대조 |
| `--only 저온해` | 저온해 계열만. 겨울 자료만 급할 때 |
| `--only 저온해,고온해,홍수해` | 월간회보 빼고 계절 보고만. 68건 |
| `--no-files` | 목록만. 파일 안 받음 |

### 대조.md — 연도를 맞대는 방식

**표 제목을 열쇠로 써.** 내용을 통째로 비교하면 글자 몇 개만 달라도 다르다고 나오는데,
표 제목은 개정되면 확실히 바뀌고 안 바뀌면 그대로거든.

세 가지를 보여줘.

1. **2023년에만 있는 표 / 2025년에만 있는 표** — 사라졌거나 새로 생긴 것.
   여기 걸리는 게 있으면 그 문서부터 읽어야 해
2. **같은 호수끼리 글자 수** — 제9호를 3년치 나란히. 분량이 확 바뀌었으면 개정된 거야
3. **저온해 보고 발행일** — 연도별로 며칠에 나왔는지. 발행 주기가 바뀌었는지 보여

양쪽에 다 있는 표가 압도적으로 많으면 **매년 같은 내용을 다시 싣는다**는 뜻이야.
그러면 우리는 한 해만 쓰면 되고, 나머지는 안 받아도 돼. 그걸 확인하려고 3년을 받는 거야.

### 본문/ 의 txt

파일 이름이 `2023_저온해_○○.txt` 꼴이야. PDF 는 `===== p.12 =====` 로 쪽 번호가 들어가서
나중에 "제9호 77쪽" 처럼 **근거 위치를 댈 수 있어.** `source` 칸에 쓸 거야.

hwpx·hwp 는 쪽 개념이 없어서 쪽 표시가 안 들어가. 대신 글자가 훨씬 깨끗해.

## 중간에 끊기면?

**그냥 다시 실행하면 돼.** 이미 받은 파일과 이미 만든 txt 는 건너뛰어.
오류 응답은 저장 안 하게 해뒀어. 저장해두면 다음에 건너뛰어서 영영 모르게 되거든.

## 다 받은 다음에 할 일

`결과/요약.md` 와 `결과/대조.md` 를 보여줘. 내가 볼 건 이 네 가지야.

1. **판독 실패가 몇 건인가** — 요약.md 맨 아래. 0이 아니면 그 형식을 따로 손봐야 해
2. **저온해 계열 40건(23년 20 · 24년 20)이 다 판독됐나** — 겨울 자료의 핵심이야
3. **연도 사이에 겹치는 표 비율** — 이게 높으면 한 해만 남기고 나머지는 버려도 돼
4. **자주 나오는 표 상위 40** — 여기에 `한계온도`·`적산온도`·`감수율` 이 보이면
   그 문서를 최우선으로 읽을게

그 다음엔 내가 `본문/` 을 직접 읽고, 기준온도·상한온도 표를 `confirmed=Y` 로 뽑아낼 거야.

## 문제가 생기면

- `.env 를 찾지 못했습니다` → 위쪽 폴더(`api테스트`)에 `.env` 가 있는지 확인
- `resultCode 13` → 오퍼레이션 이름 문제. 매뉴얼 이름만 썼으니 나오면 알려줘
- `모르는 형식 (앞 4바이트 …)` → 확장자가 아니라 내용으로 판정하는데 그래도 모르는 게 나온 거야.
  파일 이름 알려줘
- 첨부 주소 없음이 많이 나오면 → 목록에 파일 경로가 비어있는 문서야. 몇 건인지 알려줘
