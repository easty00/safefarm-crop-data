# 보관

전수수집 시절(14작물로 좁히기 전)의 결과·스크립트·문서.
**버린 게 아니라 옮긴 것이다.** 대조용으로 연다.

지금 쓰는 파이프라인은 뿌리의 `pipeline/` 이고, 그 입력은 `원본/` 이다.

## ⚠ 이 폴더는 대부분 추적되지 않는다

    보관/**/결과/     7.7GB   ← .gitignore. API 로 다시 받을 수 있다
    보관/이전결과/     132MB   ← .gitignore
    보관/gdd관련/             ← .gitignore. Elsevier 논문 전문이다

추적되는 것은 **코드(.py)와 문서(.md)뿐**이다. 약 57건.


**`.gitignore` 에서 `보관/` 을 한 줄로 막지 말 것.** 왼쪽 셋이 같이 묻힌다.

## 왜 코드를 남기나

값의 근거이기 때문이다. CLAUDE.md 가 직접 인용한다.

> 옛 추출기(`보관/품종정보/variety_stage.py`)도 중생으로 접었고 확정표 §D 수치가 그 결과다.

`조중생` 을 어느 쪽으로 접을지의 근거가 이 파일 하나뿐이다.
지우면 확정표 §D 를 왜 그렇게 정했는지 설명할 수 없게 된다.
