# 농작물재해예방정보 뜯어보기 — 사용법

## 이게 뭐 하는 거야?

농사로 **농작물재해예방정보(frcDsstrPrevnt)** 가 실제로 쓸 만한지 확인하는 프로그램이야
(`disaster_explore.py`).

이건 농진청이 **달마다 내는 회보(PDF)** 야. 140쪽쯤 되고, 기상전망·재난분석·관리기술·행동요령이 들어있어.
문제는 우리가 필요한 숫자가 **표가 아니라 줄글 안에 섞여 있다**는 거야.

```
"7월 이후 30℃ 이상 고온이 5일 이상 계속되면 내부갈색반점 급증"
"목초지(북방형)는 일평균기온 25℃ 이상이면 생육이 일시 정지"
```

이런 문장들이야. 사람이 읽으면 규칙이 보이는데, 코드가 바로 못 쓰는 형태지.

**그래서 이 프로그램은 숫자를 뽑아주는 게 아니라, "이런 문장이 몇 개나 있는지"를 세어줘.**
100개쯤 나오면 손으로 규칙화할 가치가 있고, 5개뿐이면 이 API는 접는 게 맞아.
그 판단에 필요한 숫자를 만들어주는 게 목적이야.

## 무슨 과정으로 돌아가나

```
[1단계] 회보 목록 받기
   어느 연도가 있는지 물어봄       → 2026, 2025, 2024 …
   연도마다 회보 목록을 받음        → 제9호, 제8호 …

[2단계] 회보 PDF 내려받기
   인증 없이 바로 받아져. 한 건에 보통 5~20MB

[3단계] 본문에서 조건 문장 찾기
   숫자 + 단위(℃, mm, 일 …) + 비교말(이상, 계속되면 …)
   이 셋이 한 문장에 같이 있으면 "규칙 후보"로 뽑아냄
   그 문장에 작물명이 같이 있는지도 표시
```

## 실행 방법

명령 프롬프트를 열고 프로젝트 폴더로 이동해:

```
cd "C:\Users\lecra\Desktop\safe\api테스트"
```

### 1) 먼저 올해 것 3건만 (추천)

```
python disaster_explore.py --year 2026 --limit 3
```

3~5분쯤 걸려. PDF 3건이면 30~60MB 정도야.
이것만 봐도 "문장이 몇 개나 나오나"는 판단할 수 있어.

### 2) 목록만 먼저 보고 싶으면

```
python disaster_explore.py --no-files
```

PDF를 안 받고 목록만 훑어. 30초면 끝나고 용량도 안 써.
**어느 연도에 몇 건 있는지만 먼저 보고 싶을 때** 이걸 쓰면 돼.

### 3) 올해 전체

```
python disaster_explore.py --year 2026
```

월간이라 한 해에 10~12건쯤 될 거야. 10~20분, 200MB 안팎으로 예상돼.

### 옵션

| 옵션 | 뜻 |
|---|---|
| `--year 2026` | 그 해 것만. 안 주면 전 연도 목록을 다 훑음 |
| `--limit 3` | PDF를 앞에서 3건만 받음. 시험용 |
| `--no-files` | PDF는 빼고 목록만. 빠르고 용량 안 씀 |

`--year` 없이 그냥 돌리면 **모든 연도의 목록**을 받아. 목록만으로도 몇 년치가 쌓여 있는지 보여.
다만 PDF까지 다 받으면 용량이 커지니, 처음엔 `--no-files` 나 `--limit` 을 붙이는 걸 권해.

오류 응답은 저장하지 않으니 실패한 건 진짜로 다시 시도돼.

## 다 받은 다음에 할 일

`탐사결과/재해예방정보/요약.md` 를 열어서 나한테 보여줘. 내가 볼 건 이거야.

- **규칙 후보 문장이 총 몇 개인가** — 이게 이 API를 계속 팔지 말지를 정해
- **작물명이 같이 나온 문장이 몇 개인가** — 작물별 규칙을 만들려면 이게 있어야 해.
  "30℃ 이상"만 있고 무슨 작물인지 없으면 규칙으로 못 옮겨
- **회보가 다루는 작물이 뭔가** — 로드맵에서 고른 작물과 겹치는지
- **문장 품질** — 진짜 조건문인지, 아니면 "10일 이상 지속된 장마로" 같은 과거 서술인지

내 예상은 "숫자 문장은 꽤 나오는데 작물이 붙은 건 적을 것"이야. 그러면 이 API는
판정 규칙의 출처가 아니라 **조언 문장의 참고자료**로 위상이 내려가. 그 판단을 숫자로 확인하자는 거야.

## 문제가 생기면

- `.env 안에서 AGRI_API 를 찾지 못했습니다` → `.env` 파일이 프로젝트 폴더에 있는지 확인
- `resultCode 13` → 오퍼레이션 이름 문제. 이 프로그램은 매뉴얼에 적힌 이름만 쓰니까 나오면 알려줘
- `ModuleNotFoundError: No module named 'pypdf'` → `pip install pypdf`
  (전에 확인했을 땐 이미 깔려 있었어)
- PDF는 받아졌는데 문장이 0개 → 그 회보가 이미지 스캔본일 수 있어. 알려줘
