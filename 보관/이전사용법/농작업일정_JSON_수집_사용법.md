# 농작업일정 시기정보 받기 — 사용법

## 이게 뭐 하는 거야?

농작업일정의 **다섯 번째 오퍼레이션**을 받는 프로그램이야 (`workschedule_json.py`).

```
workScheduleEraInfoJsonLst
```

이 이름은 **지금까지 한 번도 부른 적이 없어.** `farmWorkingPlanNew` 폴더의
활용가이드(.docx) 안에만 적혀 있고, 샘플소스에는 안 나와 있어서 못 찾고 있었어.
로드맵에도 오퍼레이션이 4개라고 적혀 있는데, 실제로는 5개야.

## 왜 이게 중요한가

기존에 쓰던 `workScheduleEraInfoLst` 는 월별 달력을 **HTML 표**로 줘.
시기를 알아내려면 표의 칸을 하나하나 세어야 해. 36칸(12개월 × 상·중·하순)을
세다가 한 칸만 어긋나도 열흘이 밀리지.

이 오퍼레이션은 **숫자로 바로 줘.**

```
beginMon  4      시작 월
beginEra  상     시작 순
endMon    5      종료 월
endEra    중     종료 순
opertNm   모기르기
reqreMonth 4     몇 순 동안인지
farmWorkFlag 직파재배   ← 작형! HTML 에는 아예 없음
vodUrl    농사로 동영상 주소  ← 이것도 HTML 에 없음
infoSeCodeNm 생육과정(주요농작업)  /  기상재해  /  병충해 방제
```

칸을 셀 필요가 없고, **작형 구분과 동영상 주소가 덤으로 따라와.**

## 프로그램이 해주는 것

받은 값을 그대로 저장만 하는 게 아니라 두 가지를 더 계산해 둬.

```
순번호   '4월 상순' → 9       (1월 상순이 0, 12월 하순이 35)
중앙일   '4월 상순' → 04-05   (상순 5일·중순 15일·하순 25일)
```

순번호는 정렬과 기간 계산에 쓰고, 중앙일은 나중에 기상 데이터를 붙일 때 써.
로드맵 §6-2 의 "순 → 날짜 변환" 규칙을 그대로 따랐어.

## 결과물

```
수집결과/
  농작업시기.csv       ★ 작물 × 작업 × 시기. 엑셀로 열려
  농작업시기_요약.md    ★ 이걸 나한테 보여주면 돼
  raw/                농사로가 보내준 원문 (erajson_*.xml)
```

`농작업시기.csv` 한 줄이 "어떤 작물의 어떤 작업이 언제부터 언제까지인지" 하나야.
176건 작물에 작업이 10~20개씩이니 2,000~3,000줄쯤 나올 거야.

**이 파일이 로드맵의 `crop_schedules.csv` 초안이 돼.**

## 중간에 끊기면?

**그냥 다시 실행하면 돼.** 이미 받은 건 건너뛰고 이어서 받아.

## 다 받은 다음에 할 일

`농작업시기_요약.md` 를 보여줘. 내가 볼 건 이거야.

- **정보 구분이 3가지로 나오나** — 생육과정 / 기상재해 / 병충해. 로드맵이 예상한 대로인지
- **작형(farmWorkFlag)에 무슨 값이 들어있나** — 이게 제일 궁금해.
  보통재배·촉성·반촉성 같은 구분이 나오면 시설재배를 걸러낼 수 있어
  (로드맵 §6-5: 시설재배는 노지 기상 판정과 안 맞아서 제외 대상)
- **순 번호 변환 실패가 몇 건인가** — 0이어야 정상. 많으면 월·순 값이 이상하다는 뜻
- **동영상이 몇 건이나 붙어 있나** — 농민 화면에 붙일 수 있는 자료야

## 문제가 생기면

- `resultCode 13` → 이 오퍼레이션이 실제로는 안 열려 있다는 뜻이야.
  가이드 문서에만 있고 서비스가 안 된 경우일 수 있으니 **꼭 알려줘.**
  그러면 기존 HTML 표를 칸 세어 파싱하는 방식으로 되돌려야 해
- `.env 안에서 AGRI_API 를 찾지 못했습니다` → `.env` 가 프로젝트 폴더에 있는지 확인
- 시기 항목이 0건으로 나오는 작물이 많으면 알려줘
