# 농작업일정 전수 수집 — 사용법

## 이게 뭐 하는 거야?

농사로에 있는 **농작업일정 176건을 전부 내려받는** 프로그램이야(`nongsaro_collect.py`).
작물 목록, 재배법, 월별 달력, 그리고 원본 문서 파일까지 한 번에 가져와.

이게 로드맵의 **TODO 2**야. 기준온도·목표 적산온도를 찾으려면 먼저 원본 자료가 손에 있어야 하거든.

## 무슨 과정으로 돌아가나

프로그램이 하는 일은 3단계야.

```
[1단계] 작물 목록 받기
   농사로에 "어떤 분류가 있냐" 물어봄     → 논농사·밭농사·채소·과수 … 10개
   분류마다 "무슨 작물이 있냐" 물어봄      → 총 176건

[2단계] 작물 하나하나 자세히 받기 (176번 반복)
   ① 재배법        씨뿌림 시기, 비료 주는 법, 온도 등
   ② 월별 달력      언제 심고 언제 수확하는지, 재해·병충해 시기
   ③ 원본 문서      농사로가 붙여놓은 hwpx/pdf 파일 (여기 내용이 제일 자세함)

[3단계] 목록을 엑셀로 볼 수 있게 CSV 로 저장
```

## 실행 방법

명령 프롬프트를 열고 프로젝트 폴더로 이동해:

```
cd "C:\Users\user\Desktop\safe\api테스트"
```

### 1) 먼저 3건만 시험해보기 (추천)

```
python nongsaro_collect.py --limit 3
```

`--limit 3`은 "앞에서 3개만 해봐"라는 뜻이야. 잘 돌아가는지 1분 안에 확인할 수 있어.

### 2) 잘 되면 전체 실행

```
python nongsaro_collect.py
```

**5~15분쯤 걸리고, 250MB 정도 받아.** (파일 하나가 보통 1.2MB인데, 논농사 가이드북 몇 개는 5~7MB야)

### 옵션

| 옵션 | 뜻 |
|---|---|
| `--limit 3` | 앞에서 3건만. 시험용 |
| `--no-files` | 원본 문서는 빼고 API 정보만 받기. 빠르고 용량도 적음 |


## 중간에 끊기면?

**그냥 다시 실행하면 돼.** 이미 받은 건 건너뛰고 안 받은 것부터 이어서 받아.
인터넷이 끊기거나 실수로 창을 닫아도 처음부터 다시 하지 않아도 돼.

## 다 받은 다음에 할 일

원본 문서가 hwpx 라서 그냥은 안 열려. 아까 쓴 추출 프로그램을 돌리면 돼:

```
python hwp_extract.py 수집결과\첨부파일
```

그러면 hwpx 옆에 같은 이름의 `.txt` 가 생겨. 그 안에 우리가 찾는 온도·일수 숫자들이 들어있어.
(예: 가지 문서에서 "야간 16~18℃, 주간 28~30℃", "고온기 개화 후 15~20일" 같은 게 나왔었어)

## 문제가 생기면

- `.env 안에서 AGRI_API 를 찾지 못했습니다` → `.env` 파일이 프로젝트 폴더에 있는지 확인
- `resultCode 13` → 농사로 서버가 요청을 거부한 것. 잠시 후 다시 실행
- 실패가 계속 나면 `수집결과/실패목록.txt` 내용을 나한테 보여줘

## 참고 — 왜 천천히 받나

요청 사이에 0.4초씩 쉬도록 해뒀어. 농사로는 정부 서버라 짧은 시간에 몰아서 요청하면
차단될 수 있거든. 그래서 일부러 느리게 받아.
