# 주간농사정보 · 병해충발생정보 뜯어보기 — 사용법

## 이게 뭐 하는 거야?

농사로의 **주간농사정보(weekFarmInfo)** 와 **병해충발생정보(dbyhsCccrrncInfo)** 를 확인하는
프로그램이야 (`board_explore.py`).

두 서비스는 구조가 똑같아. **목록하고 첨부파일이 전부**인 게시판이야.
상세조회 오퍼레이션이 아예 없어서 본문을 API로 받을 방법이 없어. 첨부를 열어봐야 해.
그래서 하나의 프로그램으로 둘 다 훑도록 만들었어.

## 뭘 알고 싶은 건가

로드맵은 이 둘을 "참고자료용"으로 낮춰 잡아뒀는데, 그 판단이 맞는지 숫자로 확인하는 거야.

```
1. 얼마나 자주 올라오나?       주간농사정보는 주 1회여야 맞고,
                              병해충은 연 몇 회짜리일 수도 있음
2. 첨부에 작물 이름이 나오나?   "벼 12회, 배추 3회" 식으로 세어줌
3. 숫자 조건 문장이 있나?       "25℃ 이상 계속되면" 같은 문장 개수
```

**3번이 핵심이야.** 숫자 조건이 많으면 판정 규칙의 출처가 되고, 없으면 예상대로
Claude한테 넘기는 참고 문장으로만 쓰게 돼.

## 무슨 과정으로 돌아가나

```
[1단계] 두 서비스의 목록 받기
[2단계] 서비스마다 첨부파일 몇 건씩 내려받기 (기본 3건)
[3단계] 첨부 본문을 글자로 바꿔서 작물명·숫자조건 세기
```

첨부는 hwp·hwpx·pdf가 섞여 있을 텐데 셋 다 읽을 수 있게 해뒀어.
다만 **구형 `.hwp`는 `olefile`이 있어야 읽혀.** 없으면 그 파일만 건너뛰고 나머지는 계속 진행돼
(그것 때문에 전체가 멈추지는 않아).

## 실행 방법

명령 프롬프트를 열고 프로젝트 폴더로 이동해:

```
cd "C:\Users\lecra\Desktop\safe\api테스트"
```

### 1) 목록만 먼저 (추천)

```
python board_explore.py --no-files
```

30초면 끝나. 몇 건 있는지, 얼마나 자주 올라오는지, 첨부가 무슨 형식인지가 바로 나와.
**이것만으로도 1번·일부 2번 질문에 답이 나와.**

### 2) 첨부까지 3건씩

```
python board_explore.py
```

2~5분. 서비스마다 3건씩 총 6건을 받아. 용량은 몇 MB 수준이야.

### 3) 한쪽만 보고 싶으면

```
python board_explore.py --only 주간농사정보
python board_explore.py --only 병해충발생정보
```

### 옵션

| 옵션 | 뜻 |
|---|---|
| `--no-files` | 첨부는 빼고 목록만. 빠름 |
| `--limit 5` | 서비스마다 첨부 5건씩. 기본 3 |
| `--only 주간농사정보` | 한 서비스만 |

## 중간에 끊기면?

**그냥 다시 실행하면 돼.** 이미 받은 건 건너뛰고 이어서 받아.
오류 응답은 저장하지 않으니 실패한 건 진짜로 다시 시도돼.

## 알아둘 것 하나

병해충발생정보는 매뉴얼 요청변수에 **페이지 관련 항목이 없어.** `sText`·`sType`·`sYear` 뿐이야.
그래서 한 번에 몇 건이 오는지가 서버 기본값에 달려 있어서, 목록이 짧게 나올 수 있어.
그런 경우엔 `totalCount`가 얼마로 찍히는지 알려줘 — 연도별로 나눠 받는 방법으로 바꾸면 돼.

## 다 받은 다음에 할 일

`탐사결과/주간농사정보_병해충/요약.md` 를 보여줘. 내가 볼 건 이거야.

- **올라오는 간격** — 주간농사정보가 정말 주 1회인지. 로드맵은 "주 1회 선택적 폴링"으로 잡아뒀어
- **작물 언급 횟수** — 우리가 고른 작물이 실제로 다뤄지는지
- **숫자 조건 문장 수** — 0~5개면 참고자료 확정, 수십 개면 다시 봐야 해
- **첨부 확장자 분포** — `.hwp`가 많으면 `olefile` 설치가 꼭 필요해져

## 문제가 생기면

- `.env 안에서 AGRI_API 를 찾지 못했습니다` → `.env` 파일이 프로젝트 폴더에 있는지 확인
- `resultCode 13` → 오퍼레이션 이름 문제. 매뉴얼에 적힌 이름만 썼으니 나오면 알려줘
- `olefile 이 없어 구형 hwp 는 건너뜁니다` → 정상 동작이야. 그 파일만 빠져.
  다 읽으려면 `pip install olefile`
- `읽는 방법을 모르는 형식입니다: .zip` → 첨부가 압축파일인 경우야. 알려주면 대응할게
