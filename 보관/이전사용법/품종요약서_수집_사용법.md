# 품종요약서 받기 — 사용법

## 이게 뭐 하는 거야?

품종정보 API가 품종마다 붙여놓은 **품종요약서**를 받아서 글자로 바꾸는 프로그램이야
(`variety_summary.py`).

품종요약서는 `varietyList` 응답의 `atchFileLink` 로 인증 없이 바로 받아져.
표본 3건을 열어본 결과 **첨부가 붙어 있는 비율이 100%** 였어.

## 왜 이게 필요한가

로드맵 §5-3 의 벼 검증은 이렇게 돼 있어.

```
출수 중앙일 + 55일(호남 중생종)을 누적 → 1,100~1,200℃ 나오면 파이프라인 정상
```

그런데 **"출수 중앙일"이 지금까지 우리 가정이었어.** 농작업일정에는 출수기가
"8월 상순" 같은 순 단위로만 있거든.

품종요약서에는 **품종별 출수기가 날짜로** 적혀 있어.

```
육성년도  계통명   출수기(월.일)  간장(cm)  도열병  흰잎마름병  아밀로스(%)  쌀수량(kg/10a)
2022    아미면      8.13        81       강      약          26.7       724
2025    화 연      8.11        90       강    강(K3a)        14.9       749
대비품종  다 산      8. 8        80       강    강(K1)         17.3       666
```

**가정을 관측값으로 바꿀 수 있어.** 논벼는 품종이 383건이니 숙기별 출수일 분포까지 나와.

작물마다 표 컬럼이 달라서 찾는 값도 달라져.

```
벼      출수기·간장·병저항성·아밀로스·쌀수량
감자    숙기·괴경모양·육색·상품수량·비중·식미·역병 / 휴면기간 90~100일
고구마   건물률·전분함량·수량·병해충 저항성 / "보통기 150일 재배"
```

## ⚠ 용량 주의 — 작물을 반드시 골라야 해

요약서 한 건이 **2~8MB** 야. 대부분이 품종 사진이고 글자는 500~1,000자뿐이야.

```
화연.hwp     2.3MB → 본문   540자
다온미.hwpx  8.2MB → 본문 1,042자
고선.pdf     249KB → 본문   945자
```

논벼 383건을 다 받으면 **1GB가 넘어.** 그래서 이 프로그램은 작물을 안 고르면
아예 실행되지 않게 해뒀어.

## 실행 방법

명령 프롬프트를 열고 프로젝트 폴더로 이동해:

```
cd "C:\Users\lecra\Desktop\safe\api테스트"
```

### 1) 논벼 10건으로 시험 (추천)

```
python variety_summary.py --crop 논벼
```

2~3분, 30MB 안팎. 출수기가 실제로 나오는지 확인하는 게 목적이야.

### 2) 더 많이

```
python variety_summary.py --crop 논벼 --count 50
```

50건이면 10~15분, 150MB쯤. 숙기별 분포를 보려면 이 정도는 있어야 해.

### 3) 다른 작물

```
python variety_summary.py --crop 감자
python variety_summary.py --crop 고구마
python variety_summary.py --crop 배추
```

`--crop` 은 이름에 그 글자가 들어간 작물을 다 잡아. `벼` 라고 하면 논벼·밭벼가 같이 걸려.

### 옵션

| 옵션 | 뜻 |
|---|---|
| `--crop 논벼` | **필수.** 받을 작물 |
| `--count 50` | 작물당 품종 몇 건. 기본 10 |

## 결과물

```
탐사결과/
  품종요약서/
    요약.md        ★ 이걸 나한테 보여주면 돼
    품종요약서.csv   품종별로 찾아낸 값 (출수기·성숙기·수량 등)
    원본/          받은 hwp·hwpx·pdf
    본문/          글자로 바꾼 .txt
    raw/           농사로가 보내준 원문
```

`.hwp`(구형)·`.hwpx`(신형)·`.pdf` 가 섞여 있는데 셋 다 읽어.
확장자를 믿지 않고 **파일 앞 4바이트로 형식을 판정**해 — 주간농사정보에서 이름과
내용이 어긋난 적이 있어서 그렇게 해뒀어.

## 중간에 끊기면?

**그냥 다시 실행하면 돼.** 이미 받은 파일과 API 응답은 건너뛰어.

## 다 받은 다음에 할 일

`탐사결과/품종요약서/요약.md` 를 보여줘. 내가 볼 건 이거야.

- **출수기를 찾아낸 비율** — 이게 높아야 벼 검증에 쓸 수 있어
- **상태가 '정상'이 아닌 건** — 읽기 실패가 많으면 판독 방법을 고쳐야 해
- **품종별 출수기 값** — 8.11, 8.13 처럼 날짜로 나오는지
- **용량** — 예상보다 크면 `--count` 를 줄여야 해

## 문제가 생기면

- `어떤 작물을 받을지 정해주세요` → `--crop` 을 빼먹은 거야. 용량 때문에 일부러 막아뒀어
- `ModuleNotFoundError: No module named 'olefile'` → `pip install olefile`
  (구형 `.hwp` 를 읽는 데 필요해. 지금은 설치돼 있어)
- `모르는 형식 (앞 4바이트 …)` → 예상 못 한 파일 형식이야. 그 바이트를 알려줘
- 출수기가 0%로 나오면 → 그 작물 요약서에는 그 표가 없다는 뜻이야. 다른 작물로 시험해줘
