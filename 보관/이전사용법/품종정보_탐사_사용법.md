# 품종정보 뜯어보기 — 사용법

## 이게 뭐 하는 거야?

농사로 **품종정보(varietyInfo)** 서비스가 실제로 무슨 값을 주는지 확인하는 프로그램이야
(`variety_explore.py`).

농작업일정 때처럼 **전부 받는 게 아니야.** 받기 전에 "이 서비스가 우리한테 쓸모가 있나"를
먼저 확인하는 단계야. 그래서 이름도 수집이 아니라 탐사야.

확인하려는 건 딱 세 가지야.

```
1. 숙기(조생·중생·만생)가 코드로 깔끔하게 나오나?      → 나오면 작형 구분에 쓸 수 있음
2. 수확 시기가 날짜로 나오나, 아니면 줄글 속에 섞여있나?  → 로드맵의 미확인 항목
3. 품종요약서 첨부파일이 실제로 붙어있나?               → 붙어있으면 거기서 숫자를 캘 수 있음
```

## 무슨 과정으로 돌아가나

```
[1단계] 코드표 받기
   대분류 물어봄            → 식량작물·특용작물·채소·과수·화훼·녹비작물
   대분류마다 작물코드 물어봄  → 논벼, 밀, 고추 …
   대분류마다 코드표 물어봄    → 숙기·용도·재배지대 코드가 여기 들어있음

[2단계] 작물마다 품종이 몇 건인지 세기
   품종 목록을 1건만 달라고 해서 "총 건수"만 봐. 가볍고 빨라

[3단계] 품종이 제일 많은 작물 3종만 실제로 20건씩 받아보기
   매뉴얼에 적힌 칸 14개가 실제로 몇 %나 채워지는지 세어줌
```

**2단계가 이 프로그램에서 제일 오래 걸려.** 작물 종류만큼 요청하거든.
얼마나 되는지는 1단계가 끝나야 알 수 있어서, 처음엔 `--limit` 을 붙여 짧게 해보는 걸 권해.

## 실행 방법

명령 프롬프트를 열고 프로젝트 폴더로 이동해:

```
cd "C:\Users\lecra\Desktop\safe\api테스트"
```

### 1) 먼저 짧게 시험해보기 (추천)

```
python variety_explore.py --limit 10
```

`--limit 10` 은 "2단계에서 작물 10종만 세봐"라는 뜻이야. 1~2분이면 끝나.
1단계 코드표는 `--limit` 과 상관없이 항상 전부 받아 — 그게 제일 보고 싶은 거니까.

### 2) 잘 되면 전체 실행

```
python variety_explore.py
```

작물이 몇 종인지에 따라 다른데, 대략 **3~10분**쯤 걸려.
파일은 거의 안 받으니까 용량 걱정은 안 해도 돼 (XML 몇 MB).

### 옵션

| 옵션 | 뜻 |
|---|---|
| `--limit 10` | 2단계에서 작물 10종만 센다. 시험용 |
| `--sample 20` | 3단계에서 작물당 몇 건씩 들여다볼지. 기본 20 |

## 중간에 끊기면?

**그냥 다시 실행하면 돼.** 이미 받은 건 건너뛰고 안 받은 것부터 이어서 받아.
농작업일정 수집 때랑 똑같은 방식이야.

다만 한 가지 — **오류 응답은 저장하지 않아.** 농사로가 "그런 서비스 없다"고 답하면
그걸 정상인 줄 알고 저장해버리는 실수를 막으려고 일부러 그렇게 해뒀어.
그래서 실패한 건 다시 실행할 때 진짜로 다시 시도돼.

## 문제가 생기면

- `.env 안에서 AGRI_API 를 찾지 못했습니다` → `.env` 파일이 프로젝트 폴더에 있는지 확인
- `resultCode 13` → 오퍼레이션 이름이 틀렸거나 농사로가 요청을 거부한 것.
  이 프로그램은 매뉴얼에 적힌 이름만 쓰니까, 나오면 나한테 알려줘
- `resultCode 11` → 인증키 문제
- 실패가 계속 나면 화면에 나온 메시지를 그대로 보여줘

## 참고 — 왜 천천히 받나

요청 사이에 0.4초씩 쉬도록 해뒀어. 농사로는 정부 서버라 짧은 시간에 몰아서 요청하면
차단될 수 있거든. 농작업일정 수집 때랑 같은 간격이야.
