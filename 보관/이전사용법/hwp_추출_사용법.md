# 한글 문서 글자 꺼내기 — 사용법

## 이게 뭐 하는 거야?

농사로에서 받은 매뉴얼·품종요약서·농작업일정은 한글 문서(`.hwp` 또는 `.hwpx`)라서, 한글 프로그램이 없으면 안이 안 열려.
`hwp_extract.py`는 그 안에 있는 글자를 꺼내서, 아무 프로그램에서나 열리는 `.txt`(메모장) 파일로 저장해주는 프로그램이야.

`.hwp`(구형식)든 `.hwpx`(신형식)든 **둘 다 본문 전체가 나와.** 다만 표는 칸 단위로 줄이 나뉘어서
격자 모양은 흐트러져. 값은 다 들어있으니 찾는 데는 문제없어.

## 1. 딱 한 번만 준비하기

컴퓨터에 파이썬(Python)이 깔려있어야 해. 이미 있는 걸로 보이는데, 확인하려면:

1. 시작 메뉴에서 "cmd" 검색 → 명령 프롬프트 실행
2. 아래 명령어 입력 후 엔터

```
python --version
```

버전 숫자(예: Python 3.12.x)가 나오면 이미 깔려있는 거야. 안 나오면 [python.org](https://www.python.org/downloads/)에서 설치.

그다음, 이 프로그램이 필요로 하는 부품 하나를 설치해야 해 (한 번만 하면 됨):

```
pip install olefile
```

## 2. 실행하기

명령 프롬프트에서 프로젝트 폴더로 이동해:

```
cd "C:\Users\user\Desktop\api테스트"
```

### 방법 A — 폴더 전체에 있는 hwp 파일을 한 번에 다 꺼내기 (추천)

```
python hwp_extract.py .
```

`.`은 "지금 있는 이 폴더(그리고 그 안의 모든 하위 폴더)"라는 뜻이야. 이렇게 하면 프로젝트 안에 있는 모든 `.hwp`·`.hwpx` 파일을 찾아서 전부 `.txt`로 바꿔줘.

### 방법 B — hwp 파일 하나만 꺼내기

```
python hwp_extract.py "cropEbook\OpenAPI 활용 매뉴얼 - (신)작목별 농업기술정보.hwp"
```

## 3. 결과 확인하기

실행하면 이렇게 나와:

```
[완료] OpenAPI 활용 매뉴얼 - (신)작목별 농업기술정보.hwp -> OpenAPI 활용 매뉴얼 - (신)작목별 농업기술정보.txt
```

원래 hwp 파일이 있던 자리에 **똑같은 이름의 .txt 파일**이 생겨. 그냥 더블클릭하면 메모장으로 열려.

## 4. 지금 당장 해줬으면 하는 것

`cropEbook` 폴더 안에 있는 매뉴얼(`OpenAPI 활용 매뉴얼 - (신)작목별 농업기술정보.hwp`)을 이 프로그램으로 열어서, txt 파일을 나한테 보여주면 돼. 그 안에 우리가 찾던 "오퍼레이션명"(API 세부 명령어 이름)들이 표로 적혀 있을 거야. 방법 B로 이 파일 하나만 뽑아도 되고, 방법 A로 전체를 한 번에 뽑아도 상관없어.

## 참고 — 완벽하진 않아

hwp 파일 안에는 글자뿐 아니라 표, 사진, 서식 정보도 같이 들어있어서, 이 프로그램은 **글자만** 뽑아. 표는 줄바꿈이 좀 뒤죽박죽으로 나올 수 있지만, 오퍼레이션명이나 파라미터 이름 같은 단어 자체는 다 나오니까 찾는 데는 문제없을 거야.

## 문제가 생기면

- `python은(는) 내부 또는 외부 명령...` → 파이썬이 설치 안 됐거나 경로 설정이 안 된 것. python.org에서 재설치할 때 "Add to PATH" 체크박스를 꼭 켜줘.
- `ModuleNotFoundError: No module named 'olefile'` → `pip install olefile` 다시 실행.
- `[실패] ...` 로 나오는 파일 → 파일이 손상됐거나 다른 형식일 수 있어. 그 경우엔 나한테 알려줘.
