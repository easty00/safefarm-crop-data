## 1. 확정된 것 — 다시 논의하지 않는다

| 항목 | 결정 | 근거 |
|---|---|---|
| 계산식 | `GDD = clamp((Tmax+Tmin)/2, Tbase, Tupper) − Tbase` | 인계 §1-1. Tbase 표가 이 식 전제 |
| 누적 방식 | ③ 하나. `sum_method` 컬럼 없음 | 인계 §1-3. 11작물은 어차피 역산 |
| 일평균 | (Tmax + Tmin) / 2 | 인계 §1-2. Safe-farm 스키마·논문 일치 |
| 상한 | `upper_temp` 고정값. 조건부 전환 기각 | 인계 §6-10 |
| 고온 피해 | 적산에 안 넣고 재해 경보로 따로 | 인계 §6-11 |
| 작형 | 컬럼 아님. 파종일이 정함 | 인계 §1-5 |
| 숙기 3분할 | 벼·감자·양파만. 나머지 MID 하나 | 인계 §1-6 |
| 지역 | 농업지대 20구분 + 관측지점 60곳 | `재해규칙/결과/농업지대.csv` |
| 한계온도 ≠ 기준온도 | 재해예방정보 최저온도는 base_temp 아님 | 아카이브 §1, 인계 §3-2 |

**A-1 규칙안** (인계 §5-1, 승인 전)

